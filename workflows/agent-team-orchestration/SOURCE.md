# Source

This built-in workflow adapts the concepts and examples from the
[Agent Team Orchestration Skill](https://skillhub.cn/skills/clawhub_arminnaimi/agent-team-orchestration),
version 1.0.0, into LazyMind's native workflow format.

The adaptation preserves role separation, task lifecycle ownership, explicit handoffs,
independent review gates, escalation, and failure recovery while expressing them as
five deterministic workflow stages with visible intermediate artifacts.
