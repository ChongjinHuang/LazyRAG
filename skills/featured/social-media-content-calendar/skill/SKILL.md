# 社媒内容日历

当用户希望规划一周、一个月或一次活动周期的社交媒体内容时，使用本 Skill。它是
SkillHub `social-media-operator` 的精选场景适配，专注于把运营策略落到逐日可执行的内容排期。

## 先确认输入

尽量识别以下信息；缺失时应明确假设，不要编造业务数据：

- 目标受众和核心业务目标；
- 使用的平台及每个平台的角色；
- 计划周期和关键日期；
- 内容团队人数、每日可用时间和素材产能；
- 可复用的产品资料、案例和视觉素材；
- 转化路径、表达禁区和合规要求。

## 规划方法

### 1. 建立内容支柱

根据目标选择 3–5 个内容支柱，例如用户问题、方法教学、产品价值、案例证明、品牌观点和互动内容。
每个支柱都要说明它服务的受众问题和运营目标，避免只列空泛主题。

### 2. 分配平台角色

不要把同一内容机械复制到所有平台。为每个平台定义：

- 内容目的；
- 推荐形式和长度；
- 开场方式与表达语气；
- 行动引导；
- 需要观察的指标。

### 3. 生成排期

日历中每个条目至少包含：

| 字段 | 说明 |
|---|---|
| 日期/阶段 | 具体日期、星期或活动阶段 |
| 平台 | 内容发布渠道 |
| 内容支柱 | 该条内容所属的长期主题 |
| 选题与角度 | 能直接进入制作的具体题目 |
| 形式 | 图文、口播、长文、直播、社群互动等 |
| 素材依赖 | 需要提前准备的图片、数据、案例或授权 |
| 行动引导 | 用户下一步动作，避免诱导和骚扰 |
| 负责人/工时 | 在用户提供团队信息时填写 |
| 成功指标 | 与该条内容目标对应的观察指标 |

### 4. 设置复盘节奏

按周期设置检查点，区分：

- 已知事实：用户提供或已有数据支持；
- 合理推断：基于现象提出、仍需验证；
- 待补信息：当前无法判断的数据；
- 下一步实验：能在有限周期内验证的调整。

复盘结果按“保留、停止、实验”归类，并更新下一周期内容日历。

## 输出要求

1. 先用简短段落说明目标、受众、平台角色和关键假设。
2. 使用 Markdown 表格输出完整排期。
3. 给出素材准备清单和发布前检查项。
4. 给出复盘时间、指标和调整规则。
5. 明确标记未经验证的说法，不承诺无法证明的增长结果。
6. 涉及私域转化时，包含频次限制、退出机制和用户价值，避免骚扰式运营。

## 信息不足时

如果用户只给出一句目标，可以先提供一版基于明确假设的轻量日历，同时列出最值得补充的 3–5 个问题。
不要因为缺少次要信息而拒绝生成，也不要把假设写成事实。
